# SAISON ABIDJAN

Série documentaire en épisodes. Tournage du **19 octobre au 20 novembre 2026** (33 jours).
Chaîne : Guillaume Gimenez (YouTube).

---

## Le principe

Une **saison finie**, pas une relance de chaîne. Un début, une progression, une fin.
Quand la saison est publiée, le projet est terminé. Pas de dette de cadence après.

C'est la décision structurante du projet. Tout le reste en découle.
